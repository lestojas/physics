OPTIONAL — only if your PowerPoint's VBA editor actually shows a
"ThisPresentation" item in the Project pane (under "Microsoft PowerPoint
Objects"). Many Mac builds don't show it at all, which is fine — if you
don't see it, skip this file entirely and just run the "ActivateAutoReset"
macro (in PhysicsLeagueTimer.bas) once each time you open the file instead.

If you DO have ThisPresentation available, double-click it and paste this
in for fully automatic activation on file open:

Private Sub Presentation_Open(ByVal Pres As Presentation)
    Set gTrap = New PhysicsLeagueTimerEvents
    Set gTrap.App = Application
End Sub

Because it only runs on open, close and reopen the file once after pasting
this in, to activate it for your current session too.
