Projectile Motion

An interactive simulator for the three common cases of projectile motion

1 Purely Horizontal (v0y = 0)

Launch: purely horizontal · Landing: below the launch point

2 At an angle, θi

Launch: at an angle · Landing: same height as launch point

3 At an angle, θi

Launch: at an angle · Landing: different height than launch point

Kinematic Equations

Horizontal (constant velocity, ax = 0)

Δx = v0x t
v0x = v0 cosθi  stays constant throughout the flight.

Vertical (constant acceleration, ay = −g)

vfy = v0y + ay t
Δy = v0y t + ½ ay t²
vfy² = v0y² + 2ayΔy
